# Не Разлей!

## Platform
web

## Stack
Утверждено владельцем: Phaser 4.2.1, React 19, TypeScript 5, Planck 1.5.1, Capacitor 8.

## Назначение
Мобильная 2D-игра о доставке хрупких грузов на транспорте. Основная платформа Android, дополнительная HTML5; по последнему заданию сейчас выпускается только веб-версия. Утверждён GDD v0.4: одна миссия «Сюрприз на пятом», торт и напитки, выбор физического маршрута, честная сложность, дедлайн и медали. Есть отдельная мастерская для создания новых JSON-уровней; второй публичный уровень и экономика не входят в P0.

## Ограничения
Офлайн; landscape с базой 1280×720 с адаптацией; мультитач; пауза при прерывании; оригинальные ресурсы отдельно. Аудитория и коммерческое позиционирование пока не определены.

## Визуальные требования из задания
Navy/жёлтая палитра GDD, светлый текст, стилизованная городская среда; никаких чужих логотипов. Хаб «На смене» и адаптивные горизонтальные экраны используют реальные React-контролы. Макеты 1600×900 — композиционный ориентир; игровая камера сохраняет базу 1280×720. Оригиналы ArtKit не меняются; UI не заменяется цельной картинкой.
