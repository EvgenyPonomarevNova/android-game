# Не Разлей!

## Platform
web

## Stack
Утверждено владельцем: Phaser 4.2.1, React 19, TypeScript 5, Planck 1.5.1, Capacitor 8.

## Назначение
Мобильная 2D-игра о доставке хрупких грузов на транспорте. Основная платформа Android, дополнительная HTML5. После приёмки GDDv0.4 владелец разрешил Sprint03: два контракта, офлайн-карьера и гараж с реальным физическим тюнингом. «Сюрприз на пятом» учит сохранять торт и напитки; «Пока горячее!» добавляет мокрый маршрут и остывающую еду. XP и надёжность разделены; репутация использует лучшие результаты разных заказов, тренировочные провалы не отнимают её. Первое улучшение — осмысленный бесплатный выбор. Есть отдельная мастерская новых JSON-уровней. Финальная APK и один ограниченный Android-цикл идут после интеграции новой версии.

## Ограничения
Офлайн; landscape с базой 1280×720 с адаптацией; мультитач; пауза при прерывании; оригинальные ресурсы отдельно. Аудитория и коммерческое позиционирование пока не определены.

## Визуальные требования из задания
Navy/жёлтая палитра GDD, светлый текст, стилизованная городская среда; никаких чужих логотипов. Хаб «На смене» и адаптивные горизонтальные экраны используют реальные React-контролы. Макеты 1600×900 — композиционный ориентир; игровая камера сохраняет базу 1280×720. Оригиналы ArtKit не меняются; UI не заменяется цельной картинкой.
