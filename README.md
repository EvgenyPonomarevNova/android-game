# Не Разлей!

Офлайн 2D-аркада о доставке хрупких грузов на скутере. Текущая разработка — Sprint03 /0.5.0: карьера курьера, XP/репутация/монеты, гараж с физическим тюнингом и два контракта. «Сюрприз на пятом» — торт и напитки, развилка, дедлайн и медали. «Пока горячее!» — мокрый вечер, лапша/суп и температура, которая требует выбирать между скоростью и осторожностью. Курьер и район используют ArtKit; физика — Planck с фиксированным шагом. Старые рекорды сохраняются.

0.5.0 готова к игровому плейтесту владельца. Оба контракта и карьерная цепочка проверены в production-браузере и на Game_API31 / WebView 91; старые сохранения перенесены, холодный офлайн-запуск и цифровой звук подтверждены. Финальная debug APK: `.local/apk/nerazley-0.5.0-debug.apk` (0.5.0, code 5). Человеческая оценка сложности, физический телефон, аппаратный мультитач и производительность пока не проверены. Фактический статус и ограничения — в [интеграции](docs/stage-1/integration.md), [QA](docs/stage-1/android.md) и [статусе продукта](GAME_PRODUCT_STATUS.md).

AudioKit подключён: локальная музыка меню/гаража/заказов/заезда, три слоя двигателя, UI, удары, потеря кофе и результаты. Прежние настройки сохранены; для новых данных музыка и эффекты включены, общая громкость 65%. Переключатели и проверка звука доступны в «Настройках». Оригиналы набора лежат в `assets/inbox/NeRazley_AudioKit_RUNTIME`, runtime — в `public/assets/audio`. Все звуки поставляются вместе с веб-сборкой, внешние аудиосервисы не используются.

## Запуск

Node.js 22.12+ (локально 24.18), npm и PowerShell 7 для Android-скриптов.

```powershell
npm ci
npm run dev
```

Клавиатура: W/↑ — газ, S/↓ — тормоз, затем задний ход; A/← и D/→ — наклон; Esc — пауза; R — заново. На телефоне экранные кнопки поддерживают одновременное удержание. Основная ориентация landscape.

Мастерская уровней: добавьте `?editor=1` к адресу игры. Выберите seed/шаблон/число секций и развилку, сгенерируйте черновик, отредактируйте JSON и проедьте его. Импорт и последний черновик работают локально. Кнопка «Копировать JSON» позволяет перенести данные, если браузер блокирует скачивание; нативное скачивание в автоматизированном браузере0.4.1 не подтвердилось. Тестовые заезды не меняют рекорды и карьеру. Через терминал:

```powershell
npm run level:new -- --id yard_draft --title "Новый двор" --seed 42 --preset trial --sections 4 --fork true
npm run level:check -- .local/levels/yard_draft.json
```

Генератор создаёт JSON и SVG без перезаписи существующих файлов. После проверки обеих тактик, ошибок и рестарта можно установить `status: "published"` и добавить JSON в `src/content/levels`: реестр и выбор контракта подхватят его без редактирования сцены. В игре две встроенные миссии; дополнительные JSON проходят ту же валидацию. Для включения авторского маршрута в карьеру добавьте запись с тем же levelId в `src/content/contracts.json`: описание, номер, rewardCoins/rewardXp и unlockAfter. Отдельный React-экран не нужен. Без такой записи маршрут доступен как авторский, с нулевой наградой. Валидация геометрии не гарантирует проходимость; финальные пороги медалей определяются заездами.

Баланс находится в `src/config/career.ts`, физические детали — `src/game/vehicle/Tuning.ts`. Мастерская принимает `wet-asphalt`, theme `rain-evening` и cargo `hot-meal` с temperature `{initial,ambient,coolingPerSecond,minimum,silver,gold}`. Сначала сохраните черновик с новым уникальным ID; не меняйте ID уже опубликованного контракта ради выдачи повторной награды. Условия доступа формируют последовательность через unlockAfter; избегайте циклов.

## Стек и структура

Phaser **4.2.1**, React **19.3.1**, TypeScript **5.9.3**, Planck **1.5.1** (`planck`), Vite **8.3.8**, Capacitor **8.6.2**, Preferences **8.0.1**, App **8.1.2**, Vitest **5.1.0**, CSS Modules. Версии закреплены в `package-lock.json`.

- `src/app` — React root; `src/ui` — меню, настройки, гараж, HUD и управление.
- `src/game` — сцены, мост, симуляция, физика, скутер, груз, уровни и рендеринг.
- `src/platform` — Web/Android, сохранения и звук; `src/config` — параметры.
- `assets/inbox` — оригинальные арты; `src/assets` — правила runtime-экспорта.
- `android` — Capacitor-проект; `tools` и `.github` — сохранённая инфраструктура.

## Доставка и права

Изменения — через PR и обязательный Verify repository; main не переписывается. CI проверяет исходники и web build; Android APK собирается локально.

`com.nerazley.game` — временный applicationId; утвердить до публикации. Debug APK не является release. Release-ключ не создан. Ключи, APK, SDK и снимки устройств вне Git. Собственный код: [LICENSE](LICENSE); сторонние материалы: [NOTICE.md](NOTICE.md), [DEPENDENCIES.md](docs/DEPENDENCIES.md).
