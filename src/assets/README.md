# Runtime assets

Оригиналы ArtKit v1 сохранены байт-в-байт в `assets/inbox/NeRazley_ArtKit_v1`. В `public/assets/artkit` находится только набор первого кофейного маршрута. `artkit.ts` передаёт 10 изображений в Boot/Phaser Loader; UI загружает свои отдельные PNG. Нет CDN.

`artkit-manifest.json` содержит исходный путь, размеры, SHA-256 оригинала и runtime, преобразования и статус технической проверки. Четыре фона уменьшены с 2048×1024 до 1536×768 и сохранены lossless WebP. У корпуса обрезана запечённая наземная тень; у статичного курьера — отдельный мусор слева. Остальные runtime PNG скопированы без изменения байтов.

Курьер — статичная AI-reference вырезка из переданного владельцем пакета, не кадровая анимация и не отдельное физическое тело. Источник сведений о правах: `10_FOR_CODEX/LICENSE_NOTES.md` внутри оригиналов. Самостоятельная лицензия пакету здесь не приписывается. Onest остаётся локальным Fontsource/SIL OFL 1.1; новые шрифты не добавлены.

Размеры и якоря, браузерные captures и ограничения — в `docs/stage-1/art.md`.
