# Runtime assets

Исходные арты остаются в `assets/inbox`. После выбора размеров текстур помещайте оптимизированные экспорты сюда (импорт Vite) либо в `public/assets` (Phaser Loader). `AssetLoader` поддерживает изображения, атласы и локальные FontFace, сигнализирует ошибки; `textureOrFallback` возвращает встроенную missing-texture заглушку.

Сейчас графика процедурная и оригинальная, звук синтезируется локально. Onest поставляется npm-пакетом Fontsource, SIL OFL 1.1. Никаких CDN и удалённых ассетов. Для будущих файлов фиксируйте автора, источник, лицензию и права коммерческого использования.
