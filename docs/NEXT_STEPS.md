# Следующая фаза

Готовы: чистая fixed-step физика, скутер с подвеской, кофе с физическим уроном, уровень из данных, Phaser-рендер, камера, мультитач, React-экраны, сохранения и Android build pipeline.

1. **Физика/геймплей:** на устройстве настроить сцепление, подвеску, ускорение и урон; определить законченную петлю «взять → довезти → результат → повторить», причины провала и критерии баланса.
2. **Интерфейс/графика:** принять арты в `assets/inbox`, согласовать размеры/опорные точки, подготовить runtime-атлас. Заменить геометрию, довести HUD/паузы/гараж, добавить звук с проверенными правами.
3. **Уровни:** создать 2–3 коротких маршрута в LevelData, обучающие ситуации газа/тормоза/наклона и понятные зоны доставки. Редактор пока не нужен.
4. **Android/QA:** реальный средний смартфон, frame time, долгая сессия, мультитач, вырез/жесты, блокировка, аудиопрерывания и холодный офлайн-запуск. Показатели эмулятора на телефон не переносить.
5. **Публикация:** утвердить applicationId, возрастные/магазинные материалы, собственную release-подпись и затем RuStore APK/AAB. Яндекс SDK — через PlatformAdapter отдельной задачей.

Созданы чаты «Физика и геймплей», «Интерфейс и графика», «Android и QA». Главный чат интегрирует общие контракты, зависимости и CI; в общем checkout автор на файл один. Границы: [TEAM.md](TEAM.md).
