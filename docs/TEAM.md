# Профильные чаты

Созданы по поручению владельца 17 ноября 2026. Это чаты для будущих конкретных задач; автоматически менять код после каждого сообщения они не должны.

| Чат | Ответственность |
| --- | --- |
| Не Разлей! — Физика и геймплей | `src/game/physics`, `vehicle`, `cargo`, `levels`, соответствующие тесты. Баланс транспорта, повреждений и маршрутов. |
| Не Разлей! — Интерфейс и графика | `src/ui`, `src/assets`. Экраны, HUD, touch UI, подготовка предоставленных артов; `assets/inbox` сохранять. |
| Не Разлей! — Android и QA | `android`, Android-скрипты, APK/AAB, lifecycle, устройства, frame time и release-подготовка. |
| Основной чат | Интеграция, `src/game/core`, `src/shared`, `src/config`, зависимости, lock и CI. |

Общий checkout один: не переключать ветку во время чужой работы, не откатывать чужой diff, не делать `git add .`. Автор на файл один. Для camera/rendering/input/platform владелец назначается на конкретную задачу. Контракты GameBridge, конфигурации и зависимости меняются последовательно через интегратора. Перед передачей указывать изменённые файлы и фактическую проверку. Профиль сам по себе не даёт разрешения на новую реализацию.
