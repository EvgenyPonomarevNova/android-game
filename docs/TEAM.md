Общий checkout — `codex/game-foundation`, база фундамента `554f2bb` / PR #2. Профильным чатам запрещены смена ветки, staging, commit/push/merge, reset/stash/clean и откат чужого diff. Один файл — один активный автор. Рендеринг и сцены в этом этапе закреплены за графикой; `src/platform` и общие контракты — за интегратором. Пути, отсутствующие в таблице этапа, нельзя присваивать своему профилю автоматически.

Изменение Outcome/result уже согласовано в STAGE_1: физик владеет `src/game/core/Simulation.ts`, основной чат — GameBridge, заказом/звёздами/сохранением, UI — выдачей результата сценой. Остальные изменения общих контрактов требуют передачи интегратору. Физические размеры определяют визуальные якоря. Навыки выбираются по [каталогу](skills.md), порядок взаимодействия — по [chat-coordination.md](chat-coordination.md).

Профили завершают только назначенную часть и сохраняют результат, файлы, команды/вывод, ограничения и запросы контрактов в свой отчёт. После этого интегратор выполняет общую проверку, затем передаёт Android QA фиксированную ревизию для APK и устройства. В параллельной фазе Android-чат не запускает установку, эмулятор, cap sync и APK build. Следующая фаза и следующий этап требуют передачи/приёмки, а информационное сообщение само по себе не запускает новую работу.
