# Приёмка первого игрового цикла

17 ноября 2026. Исходники объединены в `0b25f70`, Android-совместимость исправлена в `f01c712`, версия 0.2.0. Один автор каждого модуля; основной чат выполнил интеграцию без смены общего checkout. Оригиналы ArtKit и upstream-лицензии сохраняют байты в Git через `.gitattributes`.

## Общие проверки

- ESLint: exit 0. Vitest: 32 теста / 4 файла passed после исправления Android-совместимости.
- TypeScript + Vite production build: exit 0; 63 модуля. Prettier: все проверяемые исходники соответствуют стилю.
- `verify-project.ps1`: 8 PowerShell-скриптов, 92 файла / 22 навыка, 663 пути Git-индекса; exit 0. `git diff --cached --check` и проверка Conventional Commit прошли. После добавления этой приёмки число Git-путей изменится.
- При интеграции исправлены nullable `ContactEdge.other`, отсутствующий в установленном Planck `PolygonShape.getVertexCount` (использован computeAABB) и числовые атрибуты meter. Ошибка чтения формы была воспроизведена в dev-браузере до исправления; в production-переходах ниже не повторилась.
- Первый APK обнаружил отсутствующий Object.hasOwn в WebView 91 при старте заказа. Он заменён на Object.prototype.hasOwnProperty.call; тест с временно отсутствующим Object.hasOwn воспроизвёл ошибку до исправления и прошёл после него. Vite target chrome91 фиксирует проверяемую границу синтаксиса; новые runtime API всё равно требуют отдельной совместимости. Первая APK отклонена и заменена; точные итоговые метаданные — в android.md.

## Браузер

Chromium через отдельную agent-browser session. Финальный прогон выполнен на `vite preview`, порт 4173, без HMR, размер 740×360. Физика не подменялась: команды клавиатуры подавались обычными DOM KeyboardEvent на body, кнопки переходов нажимались через браузер.

1. Меню → Играть → заказ «Кофе для соседа» → Взять заказ.
2. Только газ: доставка за 12.200000000000186 с, 100% кофе, 3 звезды, 1278 очков. Данные подтверждены в `localStorage['nerazley.save']`.
3. Попробовать ещё → газ и постоянный наклон вперёд: провал «Скутер перевернулся», 0 очков. Отдельный dev-прогон также подтвердил эту ветку; время около 11 с зависит от момента подачи клавиш.
4. Продолжить к заказам → reload → Играть: лучший заезд остаётся 3/3, 100%, 12.2 с. Провал рекорд не заменяет.
5. Новый заезд → Escape → Продолжить → Escape → Выйти в меню: переходы работают.
6. 1280×720 и 740×360 просмотрены визуально. Камера с origin 0 удерживает скутер над управлением; на низком экране панели заказа/результата прокручиваются. Снимки хранятся в `.local`, вне Git.

Синтетические клавиатурные события не подтверждают аппаратный мультитач. Android-проверка точного APK находится в [android.md](android.md). Прежние результаты 0.1.0 из [VALIDATION.md](../VALIDATION.md) не считаются проверкой 0.2.0.

## Граница результата

Это первый playable slice, не магазинный релиз. Один доступный заказ, один маршрут, статичный курьер, синтезированный базовый звук. Гараж описывает единственный скутер; покупок и улучшений пока нет. Первый маршрут намеренно прост: только газ позволяет довезти кофе. Следующая задача Gameplay Polish — добавить решения о скорости и наклоне с понятной обратной связью, сохранив доступность первого заказа. Сложность и желание повторять требуют пользовательского плейтеста, одни unit-тесты этого не доказывают.
