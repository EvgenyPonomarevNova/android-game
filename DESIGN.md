# Интерфейс технического прототипа

Направление задано владельцем: яркий жёлтый, графит и тёплый светлый фон. Компактное меню слева, собственный геометрический городской пейзаж справа; в игре Canvas занимает экран, HUD сверху, мультитач снизу. Пауза явно останавливает симуляцию.

Шрифт Onest с локальной кириллицей (SIL OFL). Крупный наклонный заголовок, плотные подписи, крупные кнопки от 48 CSS px, отчётливый фокус. Оформление временное до получения артов. CSS Modules, safe-area insets, адаптация к landscape и портретным окнам. Эффекты не закрывают дорогу и груз.
