# Исходные арты

Сюда можно положить арты и референсы, когда они будут готовы. Сохраняем оригинальные имена, размеры и прозрачность; оптимизированные игровые версии создадим отдельно под выбранный движок.

Если есть, полезны исходники со слоями, отдельные спрайты/кадры, фоны и описание анимаций. Достаточно и того набора, который уже есть.

Перед публикацией в GitHub проверим объём исходников и необходимость Git LFS. Архивы и сборки игнорируются Git.
